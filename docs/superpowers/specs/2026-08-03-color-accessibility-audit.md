## 结论

`categoryChartColors`（分类饼图 7 色）里 `dustyBlue #6D8B96` / `sage #8AA17E` / `warmTaupe #B08968` 三色相互靠得太近，在中度红色弱/绿色弱模拟下会撞色；`gold #DDA63A` 对白/米色背景对比度只有 2.0-2.2:1，饼图切片上的白字百分比标签本身就难读，与色弱无关但会叠加影响。`teal`（已发生）/`gold`（计划中）/`lavender` 三色分离度够，未改动。

## 方法

用 Machado et al. (2009) 的红色弱(protanopia)/绿色弱(deuteranopia)满色盲变换矩阵，在恒等矩阵与满色盲矩阵之间按 severity 线性插值：
- severity 1.0 = 完全色盲（dichromacy），会高估问题
- **severity 0.3 / 0.5 = 轻度/中度色弱（anomalous trichromacy）**，是本次复核的目标人群，本文档所有结论都基于这一档

色差用模拟后 sRGB 的欧氏距离衡量（0-441 量级），只用于同一方法下的相对比较：<30 视为几乎同色，<60 视为难辨认，>90 视为清晰可辨。这不是色度学精确值（更严谨应该用 CIEDE2000），但足够支撑"这批颜色该不该换"的判断。

## 未改动/已知取舍

- 消费汇总图例（已发生 teal / 计划中 gold / 剩余 mutedText）：teal 与 mutedText 在色弱下会靠近（距离 33-42），但每个色点旁边都跟着文字标签，不是纯色彩编码，风险可接受，未处理。
- 只验证了红色弱/绿色弱（占色弱人群绝大多数），未针对蓝黄色弱(tritanomaly)专项优化，其发生率显著更低。
- 未引入图案/纹理等非颜色的冗余编码——图例文字已经是冗余编码，够用。
